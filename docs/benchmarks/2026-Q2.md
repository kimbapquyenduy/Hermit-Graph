## Method

- **Token bench:** real MCP server via JSON-RPC stdio. 8 standard tasks against EduMVP (Next.js, 547 files). Same task definitions before / after.
- **Hard bench:** complicated tasks (impact on 197-caller symbols, class context, semantic queries, empty-result robustness).
- **Functional bench:** 7 realistic developer scenarios. Each response auto-judged with a programmatic actionability predicate (not vibes).
- **Framework e2e:** runs each resolver's `detect()` against a real project, then scans real source files and validates resolutions against the project's symbol graph.
- **Reproducible:** `npm run bench:tokens`, `npm run bench:hard`, `npm run bench:functional`, `npm run bench:framework-e2e`.

## Reproduce

```bash
npm run test:all           # 176 tests, ~30s
npm run bench:tokens       # standard 8-task token bench
npm run bench:hard         # complicated tasks (heavy callers, classes, etc.)
npm run bench:functional   # actionability validation
npm run bench:framework-e2e [path-to-project]   # framework resolver e2e
```

All bench harnesses save JSON output for re-analysis next to the script (default `scripts/bench/`). Override target project via `HERMIT_BENCH_PROJECT=/path/to/project` or first positional CLI arg.
